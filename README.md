# Rafa Nadal Clinic India Tour 2027 — Atletas India

Interactive web brochure and print/digital PDF assets for the inaugural India tour.

## Web brochure

```bash
cd brochure-web
npm start
```

Opens a static server on [http://127.0.0.1:4173](http://127.0.0.1:4173).

## PDFs

```bash
node pdf/generate-pdf.mjs
```

Writes:

- `/cursor/stores/self/docs/brochure-print.pdf`
- `/cursor/stores/self/docs/brochure-digital.pdf`
